#Répertoire static

## Rôle 
Ce répertoire contient les fichiers statiques utilisés par l'application web.

## Fichiers principaux

### style.css
Définit l'apparence visuelle de la calculatrice, notamment la mise en page, les couleurs, les boutons et la zone d'affichage.

## Dépendances
Le fichier `style.css` est chargé par le fichier `index.html`
