#Répertoire templates

## Rôle 
Ce réptertoire contient les modèles HTML utilisés par l'application Flask.

## Fichiers principaux

### index.html
Contient l'interface utilisateur de la calculatrice. Il affiche le champ de saisie, les boutons numériques, les opérateurs et le résultat retourné par l'application Flask.

## Dépendances
Le fichier `index.html` utilise Flask pour afficher l'interface de la calculatrice et le résultat des opérations.

Il charge également le fichier `style.css` situé dans le répertoire `static`.
